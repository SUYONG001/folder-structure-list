# folder-structure-list

自动扫描文件夹并生成带体积的结构清单，输出为「文件夹名_结构清单.txt」。

## 特性
- 自动识别脚本所在路径，无需手动配置
- 自动命名输出文件，避免重名覆盖
- 文件夹/文件体积智能换算 KB/MB/GB/TB
- 可自定义最大扫描深度和首尾装订线样式

## 使用方法
1. 把 `自动生成结构清单.py` 放进你想扫描的文件夹
2. 双击运行（需已安装 Python）
3. 同目录下会生成 `xxx_结构清单.txt`

## 配置说明
编辑脚本顶部的 `MAX_DEPTH` 和 `BORDER_STYLE` 即可。

## 环境要求
- Python 3.x
